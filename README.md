# Diyabet Ürünleri

Diyabet ürünleri için geliştirilmiş, ürünleri listeleyip detaylarını gösteren, sepet ve profil ekranları içeren bir Flutter mobil katalog uygulaması.

## Kullanılan Flutter Sürümü

- Dart SDK: `^3.13.0`
- Bu sürüme uygun Flutter kararlı (stable) sürümü kullanılması önerilir (Flutter 3.32 ve üzeri).

## Çalıştırma Adımları

1. Bağımlılıkları yükleyin:
   ```
   flutter pub get
   ```
2. Bağlı bir cihaz/emülatör olduğundan emin olun:
   ```
   flutter devices
   ```
3. Uygulamayı çalıştırın:
   ```
   flutter run
   ```
